Requisito o Problemas

Requisitos indispensables


  • Conexión a internet o datos móviles:
    Es fundamental contar con una conexión estable para evitar interrupciones al momento de cargar la página o la plataforma.
  • Número de control y datos de identificación:
    Necesarios para validar tu acceso dentro del sistema.

Posibles problemas y cómo solucionarlos


  • Problema: Fallas de conexión o falta de internet/datos
    Verifica que tu red Wi-Fi sea estable o asegúrate de tener suficientes datos móviles activados antes de iniciar. Si la señal falla, intenta reiniciar tu módem o cambiar temporalmente a otra red.
  • Problema: El temporizador no avanza o la página no se actualiza.
    Actualiza la pestaña del navegador (recarga la página) unos momentos antes de que finalice el tiempo, o borra el caché si la interfaz se queda congelada.
  • Problema: Error de acceso con el número de control o el nombre no coincide.
    Revisa muy bien que no tengas errores de dedo al escribir tu número de control. Si el problema persiste, contacta al organizador o revisa la lista oficial para confirmar cómo está escrito tu nombre exactamente
